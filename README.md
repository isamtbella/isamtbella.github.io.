## 🤖 IsA, a assistente do site

O site tem um chatbot, a **IsA**, que responde em português, inglês ou espanhol conforme o idioma da página. Ela é objetiva, apresenta os serviços, pede apenas o nome da pessoa e encaminha o agendamento por e-mail.

- **Front-end:** widget de chat no próprio `index.html`, que envia a mensagem, o idioma e as últimas trocas da conversa.
- **Back-end:** repositório [isa-back](https://github.com/isamtbella/isa-back), uma API em Node.js + Express que chama a API do Gemini e hospeda no Render.
- **Segurança:** a chave da API fica só nas variáveis de ambiente do Render, nunca no código nem no GitHub.

## 🛠️ Tech Stack do Projeto

Feito com foco em performance, acessibilidade e design editorial minimalista:

- **HTML5 semântico** e SVGs customizados (elementos botânicos responsivos).
- **Tailwind CSS** (via CDN) para estilo responsivo e temas.
- **JavaScript Vanilla**, sem dependências pesadas:
  - Site trilíngue (PT / EN / ES), com atualização de metadados e links de contato.
  - Alternância de tema escuro/claro (escuro por padrão).
  - Linha do tempo horizontal interativa e blocos recolhíveis ("Ver mais").
  - Cópia rápida do e-mail com feedback visual, além de atalho para escrever no Gmail.
  - Animações de entrada (Reveal) e Scrollspy sincronizado com a barra lateral fixa.
  - Efeito de Spotlight acompanhando o cursor.
  - Chatbot IsA integrado.
- **Hospedagem:** GitHub Pages (site) e Render (API do chatbot).
