## 🛠️ Sobre o Projeto (Tech Stack)

Este portfólio foi desenvolvido com foco em performance, acessibilidade e design editorial minimalista (estilo Landing Page).

- **HTML5** Semântico.
- **Tailwind CSS** (via CDN) para estilização ágil e responsiva.
- **JavaScript Vanilla** para lógicas de interface:
  - Sistema de Internacionalização (PT-BR / EN).
  - Toggle de Tema (Dark / Light Mode).
  - Animações de entrada (Reveal) e Scrollspy na navegação lateral.
  - Efeito visual de *Spotlight* interativo.
- **Hospedagem:** GitHub Pages.
